# Changelog

## v0.1.4

**新增**
- 标题栏刷新按钮带自定义确认对话框，匹配应用暗色风格，居中显示
- 菜单"重启应用"功能（完整重启整个 Electron 应用）

**修复**
- 最大化/还原图标映射修正（窗口模式显示单层方框，全屏显示双层方框）
- 上传同名文件时自动追加 `_1`, `_2` 后缀，避免覆盖丢失数据
- Windows 路径兼容性：CLI 脚本在 Windows 命令行下正确执行
- 更新超时后的内存泄漏（正确清理子进程监听器）
- 快速崩溃时的重启竞态（清理旧定时器避免多重启）

**移除**
- 标题栏内的 DOM 确认框（存在 40px 高度限制导致显示问题，改用应用内居中对话框）
- 菜单"强制重新加载"项（整合为"重启应用"）
